# Лабораторная работа №9 — автоматический запуск тестов

Цель работы: настроить запуск автотестов через GitHub Actions при отправке
изменений в репозиторий.

В проект перенесены калькулятор и модульные тесты на `pytest` из лабораторной
работы №6. Все тесты выполняются локально, без внешних сервисов.

## Файлы проекта

- `calculator.py` — сложение, деление и проверка числа на простоту.
- `test_calculator.py` — параметризованные тесты калькулятора.
- `requirements.txt` — зависимости для запуска тестов.
- `.github/workflows/run-tests.yml` — конфигурация GitHub Actions.
- `.gitignore` — исключение виртуального окружения и служебных файлов из Git.

## Локальный запуск

Требуется Python 3.9 или новее. Команды для macOS и Linux выполняются
из директории `testing-lab-9`:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest -v
```

Ожидаемый результат — `28 passed`.

| Проверка | Число случаев |
| --- | ---: |
| Сложение, включая отрицательные и дробные числа | 6 |
| Деление, включая отрицательные и дробные числа | 7 |
| Исключение при делении на ноль | 4 |
| Определение простого числа | 11 |
| **Всего** | **28** |

Для повторного запуска из этой же директории можно использовать окружение
без активации:

```bash
.venv/bin/python -m pytest -v
```

## Автоматический запуск

Корнем репозитория должна быть директория `testing-lab-9`, чтобы файл
`.github/workflows/run-tests.yml` находился по ожидаемому GitHub пути.

Workflow `Run tests` запускается при каждом `push`. После публикации workflow
в основной ветке его также можно запустить вручную через вкладку **Actions**.
Задание выполняется на `ubuntu-latest`: получает код репозитория,
устанавливает Python 3.13 и зависимости, затем запускает `python -m pytest -v`.

Если все тесты прошли, запуск помечается зелёной галочкой. Ошибка установки
зависимостей или падение теста приводит к неуспешному завершению workflow.

Конфигурация использует официальные действия
[`actions/checkout`](https://github.com/actions/checkout) и
[`actions/setup-python`](https://github.com/actions/setup-python).
